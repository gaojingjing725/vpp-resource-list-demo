## 级联面板点击后关闭 bug 修复
- 根因：`row.onclick` 中 `renderMultiColumn(level, panel)` 调用 `columns[i].remove()` 删除了被点击的 DOM 元素。事件冒泡到 document 时 `e.target.closest('.filter-control')` 返回 null（元素已脱离 DOM），触发 `closeAllDropdowns()`，面板被关闭
- 修复：`row.onclick` 开头添加 `e.stopPropagation()`，阻止面板内点击事件冒泡到 document handler
- 验证：点击省→展开市（2 列/360px）、点击市→展开区（3 列/540px），面板均保持 show
- 重构级联面板布局：废弃 `flex-wrap: wrap`（footer 换行诉求与列不换行诉求冲突），改用 `flex-direction: column` 面板 + 独立 `.cascader-body` 行容器（`flex-direction: row; flex-wrap: nowrap`），列始终在同一行向右展开，footer 在 panel 底部自然排列。JS 新增 `ensureCascaderBody(panel)` 辅助函数
- 修复 footer "已选 0 项" 竖排：`.cascader-footer-bar-count` 被 flex 容器 `justify-content: space-between` + `flex-shrink: 1` 压缩到仅 22px，配合 `white-space: normal` 导致文字逐字换行。修复：`white-space: nowrap` + `flex-shrink: 0`，footer 高度从 83px 恢复至 45px
- 修复区域筛选框高度不一致：`.filter-input--multi` 的 `min-height: var(--input-height)` 变量未定义，实际渲染仅 30px（vs 其他框 38px）。改为 `min-height: 38px`
